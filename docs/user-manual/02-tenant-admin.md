# 租户管理后台使用手册

> 地址：`https://admin.quantaida.cloud`（租户登录）或租户子域名　账号类型：`TENANT`　适用：租户管理员/店长/前台/护理主管/财务/库管/人事

## 1. 登录与工作台

1. 选择「租户登录」，输入租户编码（如 `demo`）、账号、密码。
2. 登录后进入租户工作台：今日预约、待处理订单、会员新增、营收、库存预警、证照到期提醒。
3. 左侧菜单按角色权限显示；无权限菜单不展示，直接访问接口返回 `403`。

> 租户管理员账号不能登录平台端；租户被停用后登录返回 `40301`。

## 2. 会员与宝宝档案

### 2.1 家庭会员

- 新增会员：姓名、手机号、性别、生日、来源、标签。
- 手机号/证件号加密存储，列表展示脱敏（如 `138****8000`）。
- 同一手机号或同一 UnionID 不允许重复建档。
- 会员详情：储值、积分、卡券、宝宝、订单、预约、成长记录。
- 支持按手机号精确查询、按姓名/会员号模糊搜索。

### 2.2 宝宝档案

- 关联家庭会员，记录姓名、性别、出生日期、过敏史、健康备注。
- 成长记录：日期、身高、体重、备注、图片。
- 敏感健康信息按角色脱敏；一线人员仅看服务所需信息。

## 3. 门店、服务与排班

- **门店**：名称、地址、电话、营业时间、服务范围、配送范围、经纬度。
- **服务项目**：编码、名称、分类、价格、时长、适用年龄、封面、详情、上下架。
- **排班**：护理师 + 日期 + 时段 + 容量；预约时自动校验并占用容量。
- **员工**：档案、角色类型（护理师/育儿师/康复师等）、等级、状态。
- **证照**：证照类型、编号、到期日、附件；到期前预警。

## 4. 商品与库存

- 商品 SPU：编码、名称、分类、品牌、适用年龄、封面、图集、详情。
- SKU：规格 JSON、售价、成本、库存、安全库存、供应商。
- 库存流水：入库/出库、前后数量、业务单号、备注。
- 库存低于安全库存时在工作台预警。
- 订单支付自动扣减库存，退款自动回滚并写流水。

## 5. 订单、支付与退款

- 订单列表：订单号、会员、类型、金额、支付状态、订单状态、来源、时间。
- 新建订单：选择会员、门店、服务/商品明细，自动计算金额。
- 支付：演示环境为 Mock；真实微信支付凭证配置后切换。
- 退款：仅已支付订单可退，记录退款单、原因、金额，回滚库存。
- 取消：仅未支付订单可取消。
- 支持按订单号/会员/状态/时间筛选，导出 Excel。

## 6. 预约、派单与核销

- 预约类型：到店 / 上门。
- 创建预约：会员、宝宝、门店、服务、日期、时段、护理师、地址、联系人、电话。
- 派单：选择护理师，生成派单记录，状态 `PENDING → ACCEPTED`。
- 核销：输入 6 位核销码，完成服务。
- 改约/取消：释放排班容量，记录状态。
- 一线端接单、GPS 签到、服务记录、完成确认会回写预约状态。

## 7. 储值、积分、卡券与活动

- **储值**：充值/消费/退款均写流水；余额与流水可核对。
- **积分**：规则配置（消费赠送比例等）；订单支付自动累加并写流水。
- **卡券**：券模板（类型、面值、门槛、总量、有效期）；会员领取与使用记录。
- **活动**：亲子活动发布、报名、签到；报名名单可导出。
- 过期优惠券由每日租户任务自动置为 `EXPIRED`。

## 8. 供应商与渠道商

- **供应商**：档案、供货单、供货明细、签收、对账单、结算。
- **渠道商**：档案、报单、审核、佣金明细、额度、下级、结算。
- 供应商/渠道商登录后只能看到自己的数据，数据边界由租户 + 账号双重限制。

## 9. 报表

「报表中心」支持：

- 会员增长、预约量、订单量、营收、储值、分佣、服务质量。
- 按日期/门店/员工/服务维度筛选。
- 图表 + 明细表 + Excel 导出。

## 10. 系统配置

### 10.1 全局参数

站点名称、Logo、ICP、客服电话、SEO 标题/关键词/描述、公众号/小程序、支付、存储、多语言开关。保存即时生效；密钥字段加密保存。

### 10.2 多语言

- 语言列表启停（默认中文/英文）。
- 翻译词条维护。
- 内容多语言字段（标题/正文/SEO）分 tab 填写。
- 前台顶栏切换语言；未填项显示红点提示。

### 10.3 菜单可视化

- 选择端：公众号/PC 官网/PC 后台/小程序 tabBar/H5 底部/App 底部。
- 三栏：左侧菜单树、中间属性面板、右侧实时预览。
- 支持增删改、拖拽排序、属性保存、整树保存。
- 保存后前台/侧边栏即时刷新；清空/重置需二次确认。
- 公众号菜单「预览 → 发布」在微信菜单管理子页执行。

### 10.4 对象存储

- 5 张卡片：本地、S3、OSS、COS、MinIO。
- 选中后才显示表单；AK/SK 密码框 + 眼睛。
- 连接测试通过才可保存；切换驱动二次确认。
- 本地驱动可配置根路径与外网前缀。
- 云端驱动需服务商 SDK/凭证，未接入时上传返回 `50010`。

### 10.5 消息配置

- 4 通道：公众号模板消息、小程序订阅消息、App 推送、站内信。
- 6 短信渠道：阿里云、腾讯云、华为云、京东云、Amazon SNS、本地日志。
- 渠道全局互斥：启用新渠道自动停用旧渠道。
- 密钥掩码显示，留空表示不修改。
- 模板 CRUD：触发节点、通道、模板 ID、字段映射（如 `thing1,time2,phrase3`）。
- 同节点同通道唯一；未启用渠道时验证码降级写日志并提示。
- 真实模板 ID 需先在微信侧申请。

### 10.6 SSO

- 协议：CAS / OAuth2 / OIDC / Sa-Token。
- 只填根地址即可自动拼协议路径。
- Service 回调、账号映射、重载。
- Secret 掩码、留空不改。
- SSO 不可用时降级账号密码登录；映射失败拒绝并记录日志。

### 10.7 微信公众号

11 个子页：账号管理、数据统计、标签、粉丝、消息、模板消息、菜单、自动回复、素材、图文草稿、发表记录。详见 `docs/api.md` 微信章节。

## 11. 角色、权限与审计

- 两级 RBAC：角色 → 菜单/按钮权限；数据权限按租户/门店/本人。
- 角色：管理员、店长、前台、护理主管、护理师、育儿师、康复师、财务、库管、人事、供应商、渠道商、会员。
- 越权访问返回 `403` 并写审计。
- 审计日志支持按模块/操作人/时间检索、导出，含 `tenant_id`。
- 超管除审计日志只读外，各业务模块均可增删改查。

## 12. 个人中心

- 修改密码：输入旧密码、新密码、确认新密码。
- 查看/修改个人资料、头像。
- 消息中心：平台公告、系统通知、业务提醒。
- 退出登录。

## 13. 常见问题

| 问题 | 处理 |
| --- | --- |
| 登录提示 40301 | 租户停用/到期，联系平台续期 |
| 菜单看不到 | 角色未授权，管理员在角色管理勾选 |
| 上传失败 50010 | 当前存储驱动未接入，切换本地或联系运维 |
| 短信验证码收不到 | 渠道未启用，已降级写日志；检查渠道配置 |
| 预约提示约满 | 调整排班容量或换时段 |
| 订单不能退款 | 仅已支付订单可退；检查支付状态 |
| 导出数据为空 | 检查筛选条件与租户数据边界 |
| 修改密码后登录失败 | 确认大小写；联系管理员重置 |
