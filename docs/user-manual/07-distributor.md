# 渠道商端使用手册

> 适用：分销渠道商/合作机构　账号：租户管理员创建（演示 `dist01 / admin123`）

## 1. 登录

- 使用渠道商账号登录。
- 仅能查看本人/本机构的报单、佣金、额度、下级与结算数据。
- 个人中心支持修改密码。

## 2. 报单

1. 进入「报单」，选择客户/会员、服务或商品、金额、备注。
2. 提交后状态为「待审核」。
3. 审核通过后计入佣金；驳回会显示原因，可修改后重提。
4. 重复提交会被防重拦截；请勿多次点击。

## 3. 佣金明细

- 按时间/订单/状态查看佣金。
- 字段：订单号、客户、金额、佣金比例、佣金金额、结算状态。
- 支持导出，便于与租户财务对账。
- 退款订单会冲减对应佣金。

## 4. 额度查询

- 查看授信额度、已用额度、可用额度。
- 报单金额超过可用额度时会被拦截。
- 额度调整由租户管理员/财务操作并留痕。

## 5. 我的订单与下级

- 我的订单：本人报单产生的订单与状态。
- 下级：查看下级渠道商/推广员及其业绩（按权限）。
- 支持下钻查看明细，但不能越权查看其他渠道商数据。

## 6. 结算记录

- 按账期查看结算单、结算金额、打款状态、时间。
- 对结算有异议，提交说明并联系租户财务。
- 结算记录可导出。

## 7. 个人中心

- 修改密码、联系方式、收款账户（掩码）。
- 消息中心、协议。
- 退出登录。

## 8. 合规要求

- 不得虚假报单、刷单、重复报单。
- 不得泄露客户手机号、宝宝信息等隐私。
- 推广内容需使用租户审核过的素材。
- 违规行为将被冻结账号并追究责任。

## 9. 常见问题

| 问题 | 处理 |
| --- | --- |
| 报单被拦截 | 检查额度、防重、必填项 |
| 佣金未到账 | 查看订单是否完成/退款、结算周期 |
| 看不到下级 | 权限未开通或下级未绑定 |
| 数据为空 | 确认租户与账号归属 |
| 密码忘记 | 联系租户管理员重置 |
