## 通用约定

- 演示环境账号密码统一 `admin123`，上线前必须修改。
- 租户编码默认 `demo`；生产环境通过子域名或登录页填写租户编码。
- 平台端与租户端账号不互通：平台账号不能登录租户后台，租户账号不能进入平台端。
- 所有列表支持关键词搜索、分页；危险操作（删除、停用、清空、切换存储）均需二次确认。
- 密码修改入口：各端「个人中心 → 修改密码」。
- 遇到 403：先确认租户编码/子域名是否正确、账号是否有权限、租户是否被停用。

## 获取帮助

1. 查看对应端手册。
2. 查看 `docs/api.md` 错误码。
3. 运维问题查看 `docs/deploy-baota.md` 常见问题。
4. 提交工单时附：租户编码、账号、操作时间、接口路径、响应 `code/msg`、截图。
