# 业务一线端使用手册

> 适用：护理师、育儿师、康复师等上门/到店服务人员　入口：uni-app / Flutter App 工作台

## 1. 登录

- 使用员工账号登录（演示 `nurse / admin123`）。
- 账号由租户管理员在「员工管理」创建并分配角色。
- 仅能查看分配给自己的工单、排班、会员服务所需信息。
- 个人中心支持修改密码。

## 2. 工作台

展示：

- 待接工单、已接工单、今日完成数。
- 今日排班与下一单时间。
- 收入概览、工时统计。
- 消息与证照到期提醒。

## 3. 接单与派单

1. 收到派单后进入「待接工单」。
2. 查看会员、宝宝、服务项目、地址、时间、备注。
3. 点击「接单」，状态变为 `ACCEPTED`。
4. 如需改约/拒单，联系主管在后台调整。

## 4. 上门 GPS 签到

- 到达服务地点后点击「签到」。
- 客户端获取定位，后端记录时间、经纬度、预约号。
- 定位失败时可手动填写地址说明，并联系主管。
- 签到成功后才能填写服务记录。

## 5. 服务记录

记录内容：

- 宝宝体征：体温、身高、体重等。
- 护理项目：喂养、抚触、洗澡、脐部护理等。
- 健康观察、异常情况、处理建议。
- 现场照片（可多张，上传对象存储）。
- 客户签字/电子签名（完成确认时）。

记录提交后会员端「宝宝档案/成长记录」可见（按权限脱敏）。

## 6. 完成确认

1. 服务完成后点击「完成」。
2. 核对服务项目与时长。
3. 请客户电子签名确认。
4. 提交后预约状态变为 `COMPLETED`，生成服务记录。
5. 如客户不在场，按门店规范上传证明并备注。

## 7. 收入与排班

- 「我的收入」：按单/按月查看服务收入、提成。
- 「我的排班」：日期、时段、门店/上门、容量。
- 收入与排班由后台结算/排班数据生成，若有异议联系主管。

## 8. 个人中心

- 个人资料、证照、服务项目。
- 消息中心、隐私协议/用户协议。
- 修改密码、退出登录。

## 9. 服务规范

- 准时到达，统一工装/工牌。
- 服务前核对宝宝信息与过敏史。
- 涉及健康异常，及时建议就医并上报主管。
- 不拍摄与业务无关的客户隐私；照片仅用于服务记录。
- 不向客户泄露其他会员信息。

## 10. 常见问题

| 问题 | 处理 |
| --- | --- |
| 看不到工单 | 确认已被派单、账号状态正常 |
| 签到失败 | 开启定位权限；检查网络；联系主管 |
| 照片上传失败 | 检查存储配置/大小限制（50 MB） |
| 无法完成 | 确认已签到、记录已填、客户已签名 |
| 收入不对 | 核对完成单数与结算规则 |
| 密码忘记 | 联系租户管理员重置 |
