# 供应商端使用手册

> 适用：母婴商品/耗材供应商　账号：租户管理员创建（演示 `supplier01 / admin123`）

## 1. 登录

- 使用供应商账号登录。
- 仅能查看与本公司相关的供货单、对账单、资质与消息。
- 个人中心支持修改密码。

## 2. 供货单

状态：待接单 → 配送中 → 已送达 → 已签收。

1. 进入「供货单」，查看采购门店、商品/规格、数量、要求到货时间。
2. 接单后更新配送状态。
3. 到货后由门店/库管签收，或供应商上传签收凭证。
4. 支持按状态/日期/单号筛选。

## 3. 送货签收

- 核对商品、规格、数量、批次/效期。
- 上传送货单/签收单照片。
- 差异（短缺/破损）需备注，等待门店确认。
- 签收后生成/更新供货记录与库存流水（由门店确认）。

## 4. 对账与结算

- 「对账单」按账期汇总供货金额、已结算、未结算。
- 查看明细：供货单号、商品、数量、单价、金额。
- 对账差异提交说明，由租户财务审核。
- 结算记录可导出，便于开票。

## 5. 资质与商品

- 上传营业执照、食品经营许可证、产品质检/3C 等资质。
- 资质到期前提醒；过期可能影响供货。
- 维护供货商品与规格（需租户审核后生效）。

## 6. 消息与个人中心

- 消息：新供货单、对账结果、资质到期、系统通知。
- 修改密码、联系方式、银行账户（敏感字段掩码）。
- 退出登录。

## 7. 常见问题

| 问题 | 处理 |
| --- | --- |
| 看不到供货单 | 确认已被分配/关联供应商 |
| 无法签收 | 检查供货单状态与权限 |
| 对账金额不符 | 核对供货单、退货、折扣 |
| 资质上传失败 | 检查格式/大小与存储配置 |
| 结算延迟 | 联系租户财务，检查对账状态 |
