# 平台运营端使用手册

> 地址：`https://admin.quantaida.cloud`　账号类型：`PLATFORM`　适用：平台超管/运营/财务

## 1. 登录

1. 打开管理后台，选择「平台登录」。
2. 输入平台账号、密码（演示 `admin / admin123`）。
3. 登录后进入平台看板；平台端不会出现租户业务菜单。

> 租户账号无法登录平台端，接口会返回 `403 账号类型不匹配`。

## 2. 平台看板

展示：

- 租户总数、活跃租户、即将到期租户。
- 本月收入、待收账单。
- 最近开通/停用记录。
- 快捷入口：开通租户、套餐管理、账单、公告。

## 3. 租户管理

### 3.1 开通向导

「租户管理 → 开通租户」，按 5 步完成：

1. **基本信息**：租户名称、租户编码（英文/数字，作为子域名）、行业、联系人、手机号。
2. **选择套餐**：试用/标准/旗舰，显示席位、公众号、存储、短信、API 配额。
3. **调整配额**：可在套餐基础上单独调整，调整会留痕。
4. **初始化**：自动复制默认角色、菜单、参数、字典。
5. **生成管理员**：设置管理员账号（默认 `admin`）与初始密码。

提交后目标 ≤ 3 分钟可用；可在列表看到状态与到期时间。

### 3.2 列表与筛选

- 按租户名称/编码/联系人搜索。
- 按状态筛选：试用、正常、停用、到期。
- 查看套餐、配额使用率、到期预警。

### 3.3 停用 / 恢复 / 续期 / 删除

- **停用**：租户登录被拒、接口 403、数据保留可导出；恢复后立即可用。
- **续期**：选择时长，更新到期时间并生成账单。
- **删除**：二次确认，业务数据归档、平台留痕；不影响其他租户。
- 所有操作写平台审计。

## 4. 套餐与配额

「套餐管理」支持新增/编辑/停用：

- 套餐编码、名称、价格、计费周期。
- 五类配额：席位数、公众号数、存储 GB、短信条数、API 次数。
- 试用天数、功能清单。

配额超限策略：

| 类型 | 超限表现 |
| --- | --- |
| 席位 | 新增用户被拦截，提示升级 |
| 公众号 | 新增公众号账号被拦截 |
| 存储 | 上传被拦截 |
| 短信 | 发送被拦截 |
| API | 开放接口返回 `40205` |

## 5. 账单与计费

- 按账号数/席位数/套餐生成账单。
- 支持按租户、账期、状态筛选。
- 标记已付后记录支付时间与操作人。
- 支持导出 Excel，便于财务对账。

## 6. 公告

- 新增公告：标题、内容、定向租户/全体、有效期。
- 发布后租户后台与会员端消息中心可见。
- 查看已读统计，支持再次提醒。

## 7. 平台审计

- 按租户、模块、操作人、时间筛选。
- 记录登录、开通、停用、续期、配额调整、删除等敏感操作。
- 平台审计与租户审计分离；平台端可下钻租户审计（只读）。

## 8. 平台账号与角色

- 平台角色：超管、运营、财务。
- 超管拥有全部权限；运营负责租户与公告；财务负责套餐与账单。
- 平台账号与租户角色隔离，不可复用。
- 个人中心支持修改密码。

## 9. 常见问题

| 问题 | 处理 |
| --- | --- |
| 开通后无法登录 | 检查租户状态、管理员账号、租户编码 |
| 配额显示不一致 | 等待配额统计任务刷新，或手动重算 |
| 账单金额异常 | 核对套餐价格、席位数、账期 |
| 误停用租户 | 立即恢复；检查审计记录并通知租户 |
| 删除租户后需要数据 | 从归档/备份恢复，联系运维 |
