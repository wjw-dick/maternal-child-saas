# 小程序 / H5 会员端使用手册

> 入口：微信小程序或 `https://app.quantaida.cloud`（租户子域名如 `demo.quantaida.cloud`）　适用：会员/家长

## 1. 登录与绑定

- 小程序：微信授权登录，后端通过 code2Session 获取 openid/UnionID，自动绑定家庭会员。
- H5/App：手机号 + 密码或微信授权登录。
- 同一 UnionID 在小程序、公众号、H5、App 共用一套会员、订单、积分、宝宝档案。
- 仅本人及家庭成员数据可见，不能查看其他会员。

> 演示环境未接真实微信凭证时使用 Mock 登录；生产需配置 AppID/AppSecret 与合法域名。

## 2. 首页

- Banner、快捷入口、热门服务、严选商品、附近门店、公告、资讯。
- 下拉刷新、上拉加载。
- tabBar 名称由后台「菜单可视化 → 小程序 tabBar」配置，保存后重新进入生效。

## 3. 服务与预约

1. 进入「服务」，按分类筛选，查看价格、时长、适用年龄、详情。
2. 点击「立即预约」。
3. 选择宝宝、门店、服务、日期、时段、护理师（可选）。
4. 到店/上门：上门需填写地址、联系人、电话。
5. 提交后生成预约号与 6 位核销码。
6. 「我的预约」可查看状态、改约、取消；到店出示核销码。

预约状态：待确认 → 已确认 → 已完成 / 已取消。

## 4. 商城与订单

- 商品列表/详情：主图、规格、价格、库存、详情。
- 加入购物车/立即购买，选择 SKU 与数量。
- 提交订单：选择门店/收货信息、备注；重复提交会被拦截。
- 支付：演示环境 Mock 支付；生产接入微信支付后跳转。
- 订单列表：待支付、已支付、已完成、已退款、已取消。
- 售后：已支付订单可申请退款，填写原因，等待审核。
- 支付成功累加积分，生成积分流水。

## 5. 会员中心

- 会员等级、储值余额、积分、优惠券。
- 我的订单、我的预约、我的活动。
- 宝宝档案：新增/编辑宝宝，查看成长记录（身高/体重/图片）。
- 储值流水、积分流水、卡券使用记录。
- 消息中心：订单、预约、活动、系统通知。
- 个人中心：头像、昵称、手机号、协议、多语言、修改密码。

> 会员端「修改密码」需先验证旧密码；微信授权用户可设置密码后使用账号登录。

## 6. 亲子活动

- 活动列表/详情：时间、地点、名额、费用。
- 报名：选择宝宝/参与人，提交报名。
- 我的活动：查看报名状态、取消报名（按活动规则）。
- 现场签到由员工端/一线端完成。

## 7. 多语言与分享

- 顶部/个人中心切换中文/English。
- 服务/商品/活动详情支持分享给微信好友。
- 分享来源标识写入订单/表单，便于渠道统计。
- H5 与小程序同源，UnionID 数据一致。

## 8. 常见问题

| 问题 | 处理 |
| --- | --- |
| 微信登录失败 | 检查 AppID、合法域名、code 是否过期 |
| 预约提示约满 | 换时段或联系门店加排班 |
| 支付后订单未更新 | 下拉刷新；查看支付回调日志 |
| 看不到宝宝档案 | 确认 UnionID 绑定与会员归属 |
| tabBar 名称未更新 | 退出重进小程序；检查后台菜单保存 |
| 收不到消息 | 检查消息通道与订阅授权 |
| 修改密码失败 | 检查旧密码；微信用户先绑定手机号 |
