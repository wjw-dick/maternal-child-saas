# 员工端使用手册

> 适用：前台、店长、库管、财务等门店员工　入口：uni-app / 管理后台

## 1. 登录

- 使用员工账号登录（演示 `clerk / admin123`）。
- 账号由租户管理员创建，角色决定可见菜单与操作权限。
- 个人中心支持修改密码。

## 2. 今日预约与核销

- 首页展示今日预约：时间、会员、宝宝、服务、护理师、状态。
- 会员到店后输入 6 位核销码，核对身份后核销。
- 核销后状态变为 `COMPLETED`，可继续创建服务记录。
- 支持按日期/状态/护理师筛选。

## 3. 会员开卡与储值

1. 搜索会员（手机号/姓名/会员号），无档案则新建。
2. 开卡/升级会员等级。
3. 储值充值：选择金额、支付方式，确认后写充值流水。
4. 储值消费：输入消费金额/关联订单，写消费流水。
5. 余额不足时提示；退款需按财务流程操作。

> 手机号/证件号加密存储，界面脱敏展示。

## 4. 商品扫码与库存

- 扫码查询商品/SKU、价格、库存。
- 库存查询：按门店/商品/规格筛选。
- 调拨：选择源门店/目标门店、SKU、数量，提交调拨记录。
- 入库/出库写库存流水；低于安全库存预警。
- 盘点差异需备注原因。

## 5. 订单处理

- 查看订单、支付状态、履约状态。
- 协助会员下单/支付（演示 Mock）。
- 退款/取消按权限与订单状态执行。
- 打印/出示小票，核对明细。

## 6. 排班与报表简报

- 查看本门店排班、护理师可用时段。
- 日报/周报：预约量、到店率、订单量、营收、库存预警。
- 数据仅限本门店/本租户范围。

## 7. 个人中心

- 修改密码、个人资料。
- 消息中心、协议。
- 退出登录。

## 8. 常见问题

| 问题 | 处理 |
| --- | --- |
| 核销码无效 | 核对 6 位码、预约状态、租户 |
| 储值无法充值 | 检查权限与支付配置 |
| 扫码无结果 | 确认 SKU 已建档、条码正确 |
| 库存不足 | 调拨/补货；检查安全库存 |
| 订单不能退款 | 仅已支付订单可退；检查权限 |
| 报表数据为空 | 检查日期/门店筛选 |
